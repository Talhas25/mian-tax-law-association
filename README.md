# Mian Tax Law Association Website

Professional advocate-style website for Mian Tax Law Association. 
Provides tax consultancy services in Pakistan, including income tax, sales tax, FBR compliance, and legal representation. 
Features a consultation booking form, responsive design, and SEO-optimized structure.

## Features
- Income Tax Return Filing for Individuals & Businesses
- Freelancer Tax Guidance
- Sales Tax & FBR Compliance
- Legal Representation in Tax Matters
- Consultation Booking Form (email notifications)
- Fully Responsive & SEO Friendly

## Technology Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages (for hosting)
